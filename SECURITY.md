# Политика безопасности Fluffy

## Поддерживаемые версии

Исправления безопасности вносятся в ветку `main`. Для более ранних снимков кода отдельные исправления не гарантируются.

## Как сообщить об уязвимости

Отправьте приватный отчёт через [GitHub Private Vulnerability Reporting](https://github.com/ghostfaccee/Fluffy/security/advisories/new). Если форма недоступна, напишите на [fluffy.social.network@gmail.com](mailto:fluffy.social.network@gmail.com) с темой `Fluffy: security report`.

Укажите затронутый компонент, ветку или хеш коммита, условия возникновения проблемы и возможные последствия. Если можете, приложите описание наблюдаемого поведения на локальном экземпляре. Удалите из материалов пароли, токены и персональные данные.

Не публикуйте сведения об уязвимости в открытых issues, pull requests или обсуждениях. Сопровождающие изучат отчёт и при необходимости запросят детали по тому же приватному каналу. Согласуйте публичное раскрытие с сопровождающими.
