# Руководство по фронтенду

## Быстрый старт

В папке `frontend` выполните:

```bash
npm install
npm run dev
```

## Команды

```bash
npm run dev   # запуск для разработки
npm run build # сборка для продакшена
```

## Структура

Код находится в `src`:

- **`app`** - общая настройка приложения: маршрутизация, оболочки страниц, глобальные стили и связывание модулей.
- **`modules`** - функциональные модули: авторизация, чаты, группы, профили и другие разделы. Внутри модуля находятся его страницы, компоненты, хранилища и сетевые функции.
- **`shared`** - общие компоненты, вспомогательные функции и инфраструктура, используемые несколькими модулями.
- **`assets`** - изображения и другие статические ресурсы, обрабатываемые сборщиком.
- **`main.js`** - точка входа приложения.

## Где и что менять

- **Новая страница:** создайте компонент в `src/modules/<модуль>/pages`, добавьте маршрут в `routes.js` соответствующего модуля. Для нового модуля подключите его маршруты в `src/app/router/index.js`.
- **Компоненты раздела:** размещайте в `src/modules/<модуль>/components`.
- **Общие элементы интерфейса:** размещайте в `src/shared/ui`, если они действительно используются несколькими модулями.
- **Состояние:** хранилища конкретного раздела находятся в `src/modules/<модуль>/stores`. Общая инфраструктура, например WebSocket, - в `src/shared/stores`.
- **Запросы:** используйте клиент `src/shared/api/client.js`. Сетевые функции конкретного модуля при необходимости выносите в его папку `api`.
- **Переиспользуемая логика:** относящуюся к одному модулю оставляйте внутри него; общую размещайте в `src/shared/composables`. Логику связывания модулей на уровне приложения - в `src/app/composables`.
- **Стили:** глобальные файлы находятся в `src/app/styles` и подключаются через `index.css`. Стили отдельных компонентов по возможности держите в самих `.vue`-файлах. Порядок глобальных импортов меняйте осторожно: он влияет на каскад.
- **При изменении адреса бэкенда** для локальной разработки обновите `server.proxy['/v1'].target` в `vite.config.js`. По умолчанию используется `localhost:8000`. Эта настройка относится к серверу разработки, а не к готовой продакшен-сборке.

Для импортов из `src` используйте алиас `@`, например:

```js
import { api } from '@/shared/api/client'
```

## Принципы

Группируйте код по функциональности: всё, что относится к одному разделу, держите в его модуле. В `shared` выносите только действительно общие части, а в `app` - настройку приложения и взаимодействие между модулями.

Не создавайте заново старые корневые папки `views`, `components`, `stores` и `api`. Не обращайтесь к API напрямую из компонентов в обход общего клиента. Данные, зависящие от аккаунта, очищайте при смене сессии, а локальный кеш привязывайте к пользователю.

Добавляйте новые абстракции только тогда, когда это действительно необходимо. После изменений запускайте `npm run build`; при изменении авторизации, кеша или WebSocket дополнительно проверяйте выход и вход другим аккаунтом.
